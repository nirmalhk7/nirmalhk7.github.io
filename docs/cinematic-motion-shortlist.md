# Cinematic homepage motion shortlist

Reviewed against this site's Next.js 14 Pages Router, React 18, Tailwind 3, existing Framer Motion, and 200 KiB gzip initial-route budget. The chosen sequence is original code; no registry component is installed.

| Source and candidate | Dependencies, access, and fit | Decision for this portfolio |
| --- | --- | --- |
| [Aceternity Sticky Scroll Reveal](https://ui.aceternity.com/components/sticky-scroll-reveal) | Free catalog component; `motion`. Its React layout is portable to Pages Router and Tailwind 3 [per the official catalog](https://ui.aceternity.com/ai-recommendations). Premium blocks have a [separate paid license](https://ui.aceternity.com/pricing). | **Reference only.** Borrow the long, pinned chapter rhythm, but replace the generic text/image swap with a beach-to-system handoff and four factual stages. No source copied. |
| [Magic UI Animated Beam](https://v3.magicui.design/docs/components/animated-beam) | Free, [MIT-licensed library](https://github.com/magicuidesign/magicui); React, Tailwind, and Motion. Portable to Pages Router. | **Adapt the technique.** A single vermilion route connects four stages. Use custom SVG geometry and scroll progress instead of the stock perpetual glowing beam. No source copied. |
| [React Bits Scroll Reveal](https://reactbits.dev/c/text-animations) and [Scroll Expand](https://reactbits.dev/c/animations) | Free React library with CSS and Tailwind variants; some scroll text effects require GSAP. Its [MIT + Commons Clause license](https://github.com/DavidHDev/react-bits/blob/main/LICENSE.md) permits use in this site, subject to its redistribution limit. [Scroll Mask](https://pro.reactbits.dev/docs/components/scroll-mask) is Pro. | **Reject.** Character reveals delay essential recruiter information; the Pro mask is unavailable. Use a photographic crop with original code. |
| [Skiper Image Reveal](https://skiper-ui.com/v1/skiper71) | Pro license key required; Framer Motion and Lenis. Technically portable to Pages Router, but its progress UI and long gallery do not serve this story. | **Reject.** No existing Pro license; do not buy or copy it. |
| [8bitcn/ui](https://www.8bitcn.com/docs) | Free core, [MIT license](https://github.com/TheOrcDev/8bitcn-ui/blob/main/README.md), shadcn/Tailwind React components; Pages Router integration is possible with setup. | **Reject.** Pixel borders and 8-bit texture conflict with the personal photograph and engineering editorial tone. |
| [Kokonut UI](https://kokonutui.com/docs) | Free core, [MIT license](https://github.com/kokonut-labs/kokonutui/blob/main/README.md), React/Motion; current components require Tailwind 4. Pro components are separate. | **Reject.** This project uses Tailwind 3; migrating the site for a decorative component would add risk and weight. |

Motion thesis: the coastline compresses to a narrow horizon, then a vermilion path carries the eye through Interface, Services, Delivery, and Infrastructure. The photo remains the first frame and the source of the visual transition. All text and links render in server HTML; motion is an enhancement on roomy desktop viewports. The motion controller loads separately and uses GSAP ScrollTrigger for a single scrubbed timeline. Navigation and form feedback stay short in the existing UI layer.
