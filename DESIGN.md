# Portfolio design direction

Hiring-focused editorial refinement of the existing homepage. Preserve Outfit headings/body, Plex Mono metadata, #f5f2eb paper, #202321 ink, #19211f dark surfaces, and #c43b31 red (#a92f27 hover).

Sequence: photographic hero, experience, projects, latest writing, about, contact. Hero retains one bold backend headline and concise supporting evidence. Remove the pinned four-chapter introduction. Whirlwind leads the projects with a source-backed, simplified workflow diagram; the existing four projects remain in order below it.

Cap homepage content at 1200px; use 32px desktop / 22px mobile gutters. Section spacing is 88px desktop / 56px mobile. Section headings are 40–56px; hero is larger. Use crisp rules and flat editorial rows rather than decorative cards. Red marks actions, active states, focus, and diagram highlights.

Writing uses two columns on desktop and a single column on mobile. About combines the existing trees photo, biography, professional links, and disclosures. All content is in normal document flow. Reveal effects are progressive enhancement; reduced motion stays static. Preserve functional section IDs, analytics, and real contact controls.

Implementation path: code first. Verify desktop/tablet/mobile together, fix findings in one batch, and confirm once. No new imagery, animation library, metrics, testimonials, or invented product interface.
